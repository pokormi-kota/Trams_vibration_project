## Environment
- Python 3.12, Jupyter Lab


## Rules for Jupyter notebooks
- Use the Jupyter MCP for all .ipynb operations (read, edit, insert, delete, execute).
- Do not use the built-in NotebookEdit tool.
- Execute cells to verify code works. Do not assume correctness.
- If the only change to a cell is in comments, do not execute it, unless explicitly asked.
- Use %pip install (not !pip install) for packages.
- Prefer .head() and .shape over dumping full DataFrames.
